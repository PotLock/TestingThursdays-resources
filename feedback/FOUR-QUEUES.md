# Four Queues

Keep these separate.

## Bugs

Something behaves incorrectly.

→ engineering issue tracker.

## Product problems

Software may technically work, but users struggle.

→ product/research backlog.

## Requests

Users explicitly ask for something.

→ persistent request board if volume justifies it.

## Research questions

Evidence is insufficient.

→ next experiment.

Do not automatically turn uncertainty into features.
