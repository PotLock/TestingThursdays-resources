# Feedback Schema

Capture evidence before solutions.

```text
PROJECT
TESTER TYPE
TESTED JOURNEY
GOAL
OBSERVED
EXPECTED
CATEGORY
SEVERITY
REPRODUCIBILITY
EVIDENCE
EXACT QUOTE (optional)
SOURCE
```

## Categories

- BUG
- USABILITY
- COPY
- PERFORMANCE
- TRUST
- ACCESSIBILITY
- DESIRABILITY
- FEATURE REQUEST
- RESEARCH QUESTION

## Source

- target user;
- plausible user;
- peer founder;
- domain reviewer;
- automated QA;
- AI audit;
- analytics;
- support.

Never represent AI or automated findings as real user sentiment.
