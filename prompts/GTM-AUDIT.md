# GTM Audit Prompt

```text
Help test this startup's go-to-market assumptions.
Ask one question at a time about:

TARGET USER
PROBLEM
URGENCY
CURRENT ALTERNATIVE
WHERE USERS GATHER
MESSAGE
ACQUISITION CHANNEL
ACTIVATION
RETENTION
BUYER / REVENUE

Then identify the three weakest assumptions and propose the cheapest real-world experiment for each that can reasonably run before next Thursday.
Do not treat generic social-media posting as a complete channel strategy.
```
