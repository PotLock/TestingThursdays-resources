# Break My App Prompt

```text
Act as my QA copilot while I manually test this product.
Give me only the next 3 highest-value tests based on the current screen/state.

Focus on:
- invalid/empty/long input;
- repeated actions;
- back/refresh/restart;
- interrupted workflows;
- denied permissions;
- stale sessions;
- duplicate actions;
- recovery paths;
- boundary values;
- state transitions.

When I find something, help me reproduce it and write evidence-based feedback.
Do not invent a failure I did not observe.
```
