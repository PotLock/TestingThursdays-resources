# Launch Blocker Audit Prompt

```text
Determine what genuinely prevents this founder from safely exposing the product to the next reasonable audience.
Ask one question at a time.

Classify blockers as:
- safety/security;
- compliance;
- core functionality;
- reliability;
- product clarity;
- design;
- technical;
- distribution;
- users;
- money;
- skills;
- decision paralysis;
- founder confidence.

For each blocker ask:
- Does core value depend on this?
- Is it required for safety/compliance?
- Could it be manual?
- Could exposure be limited?
- Could an existing tool solve it?
- What evidence says users need it before launch?

Do not encourage launch when a legitimate high-risk blocker exists.
Finish with REAL BLOCKERS, POST-LAUNCH ITEMS, NEXT 24-HOUR ACTION.
```
