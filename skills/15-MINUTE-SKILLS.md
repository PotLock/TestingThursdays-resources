# 15-Minute Skills

Good micro-sessions for a founder lab:

- define activation;
- write a good bug report;
- run a five-second test;
- recruit the first 5 users;
- cut an MVP;
- create a PostHog-style funnel plan;
- define a B2B ICP;
- write a cold outreach message;
- create the first Maestro flow;
- audit store metadata;
- identify the current constraint;
- create a launch gate;
- write a rollback trigger;
- classify feedback correctly;
- create one distribution experiment.

Every micro-skill should end with an artifact, not just understanding.
