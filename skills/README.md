# Skills Library

Testing Thursdays should build founder capability, not dependence on facilitators.

Each skill should have a short practical version and a definition of competence.

- prioritization;
- scope reduction;
- constraint identification;
- reversible decisions;
- weekly commitment sizing;
- experiment design;
- evidence evaluation;
- delegation;
- documentation;
- asking for help;
- killing low-value work.
