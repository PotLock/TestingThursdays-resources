# Ship Sprint

Spend 30–45 minutes doing work, not discussing it.

Good outcomes:

- fix and verify a bug;
- change and deploy a landing headline;
- create analytics event/funnel;
- submit a test build;
- write and run a regression test;
- contact 10 users;
- create a B2B account list;
- send 5 prospect messages;
- configure basic error monitoring;
- remove a nonessential feature.

At the end ask:

> What exists now that did not exist 45 minutes ago?
