# Breakout Formats

Route by constraint rather than forcing everyone through usability testing.

- **VALIDATE** — problem/user evidence.
- **TEST** — usability and QA.
- **UNBLOCK** — technical/execution issue.
- **LAUNCH** — production readiness and scope.
- **GTM** — first users/distribution.
- **B2B SALES** — ICP, discovery, pilots, outreach.
- **DATA** — activation/funnel evidence.
- **RETENTION** — churn/cohorts/re-entry.
- **MONETIZE** — pricing/paywall/business model.
- **SHIP SPRINT** — actually complete work.
