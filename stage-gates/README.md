# Stage Gates

Stages are not titles. They are exit conditions.

## Problem → Validation

You can name a specific user and problem worth investigating.

## Validation → Prototype

You have credible evidence that the problem exists and understand at least one current workaround.

## Prototype → MVP

Target users can attempt the proposed core journey and you have learned enough to implement only the essential value path.

## MVP → Controlled Beta

- core value works end-to-end;
- critical known failures are understood;
- basic analytics and error monitoring exist where appropriate;
- there is a support/contact path;
- release can be limited to a manageable audience;
- no known unresolved critical safety/security/data-integrity blocker.

## Controlled Beta → Public Launch

- major core-flow issues from beta are addressed;
- production configuration is verified;
- monitoring and support are ready;
- rollback/recovery is understood;
- privacy/platform/compliance requirements relevant to the product are reviewed;
- the team can handle expected user volume.

## Launch → Activation

Users can access the product and the activation event is measurable.

## Activation → Retention

You understand whether activated users return at the cadence appropriate to the product.

## Retention → Revenue/Growth

There is enough repeat value to test monetization and/or repeatable acquisition without simply magnifying a broken product.
