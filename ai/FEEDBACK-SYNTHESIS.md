# Feedback Synthesis Prompt

```text
Cluster these testing observations by underlying problem.
Preserve the original observations and do not convert AI interpretation into fact.

For each cluster provide:
- category;
- number of observations;
- target-user vs peer sources;
- severity;
- affected journey;
- strongest evidence;
- likely hypothesis;
- confidence;
- recommended next step: FIX / TEST MORE / DEFER / REJECT.

Separate bugs, usability, trust, performance, accessibility, desirability, and explicit feature requests.
```
