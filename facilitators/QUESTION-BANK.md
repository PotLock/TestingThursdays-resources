# Facilitator Question Bank

## When someone is stuck

- What specifically is not working?
- What changed?
- Can it be reproduced?
- What have you tried?
- What would solving this unlock?

## When someone is overbuilding

- Which user evidence supports this?
- What happens if you do not build it?
- Can core value work without it?
- Can it be manual?

## When someone will not launch

- What exactly prevents five target users from using it?
- Is that blocker safety/compliance/core functionality or discomfort?
- Can exposure be reduced?

## When someone has no users

- Who exactly needs this?
- Where are ten of them?
- Can you contact them before leaving today?

## When someone says “marketing”

- Which audience?
- Which channel?
- Which message?
- How many attempts?
- What happened?
