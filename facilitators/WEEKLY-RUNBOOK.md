# Weekly Runbook

A repeatable three-hour example.

## Before session

Review founder submissions:

- current stage;
- next end state;
- blocker;
- B2B/B2C/product type;
- what needs testing;
- target users needed;
- last commitment;
- relevant skills in the room.

Pre-assign breakout groups when attendance is large.

## 0:00–0:15 — Arrival / evidence check

Founders update SHIPPED / NOT SHIPPED and attach evidence.

## 0:15–0:30 — 60-second standups

Only:

- Built
- Learned
- Blocked
- Need

## 0:30–1:15 — Breakouts

Route to Validate, Test, Launch, GTM, B2B Sales, Data, Retention, Monetize, or Unblock.

## 1:15–1:35 — Feedback synthesis

Separate observations, hypotheses, and solutions.

## 1:35–2:00 — Blocker clinic / GTM clinic

Attack the highest-value constraints.

## 2:00–2:35 — Ship sprint

Fix, deploy, configure analytics, send outreach, create test, submit build, or otherwise move the project.

## 2:35–2:50 — Demo evidence

Show what changed.

## 2:50–3:00 — Commitments

Every founder leaves with:

- end state;
- constraint;
- next action;
- deadline;
- evidence expected next week.
