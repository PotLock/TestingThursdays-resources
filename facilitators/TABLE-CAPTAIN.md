# Table Captain Guide

Ideal breakout size: roughly 4–6 people.

## Roles

- founder;
- primary tester;
- observer;
- recorder;
- optional AI driver;
- captain/timekeeper.

## Captain responsibilities

1. Keep founder context under 2 minutes.
2. Ensure a real mission/question exists.
3. Protect the test from founder intervention.
4. Make observers capture evidence.
5. Stop solution storms before diagnosis.
6. End with a decision, next action, owner, and deadline.

## Output

```text
Founder objective
Current stage
Evidence gathered
Primary finding
Decision
Next action
Owner
Deadline
```
