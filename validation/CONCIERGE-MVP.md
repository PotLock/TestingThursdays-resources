# Concierge MVP

Use a concierge MVP when the outcome can be delivered manually before the infrastructure deserves automation.

## Track

- request type;
- time per user;
- repeated manual steps;
- error rate;
- user reaction;
- whether the outcome creates value;
- which steps should remain manual;
- which steps become the automation threshold.

## Good candidates

- matching;
- reporting;
- recommendations;
- onboarding assistance;
- data entry;
- lightweight research services.

Do not use manual work to simulate or bypass safety, financial, regulatory, or privacy controls that must be real.
