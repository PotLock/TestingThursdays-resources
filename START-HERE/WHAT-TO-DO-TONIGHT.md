# What Should I Do Tonight?

When overwhelmed, use this sequence.

1. Write the next meaningful end state.
2. Name the single constraint.
3. Decide whether the constraint needs a **user, test, code change, decision, specialist, tool, or sale**.
4. Choose an action that can finish within 60–120 minutes.
5. Produce an artifact or evidence before stopping.

Examples:

- unclear demand → contact 5 target users;
- unclear onboarding → watch 3 first-time users attempt it;
- broken core flow → reproduce, fix, add regression test;
- no analytics → instrument one activation event and verify it;
- B2B no customers → build 20-account list and send first 5 messages;
- not launch-ready → run Launch Readiness Lite and choose alpha/beta/public level;
- too many features → run Build / Buy / Manual / Delete.

## Do not end with

- “research more”;
- “work on the product”;
- “improve marketing”;
- “finish backend.”

End with a concrete action and evidence.
