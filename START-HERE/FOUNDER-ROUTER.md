# Founder Router

Use this before choosing a resource or breakout.

## Step 1 — What stage are you at?

- **Problem:** no meaningful evidence yet.
- **Validation:** speaking with target users and testing assumptions.
- **Prototype:** users can experience the proposed workflow.
- **MVP:** core value works end-to-end.
- **Launch Ready:** controlled external release is technically and operationally reasonable.
- **Market:** real users can access the product.
- **Activation:** focus is getting users to first value.
- **Retention:** focus is repeated value.
- **Revenue:** focus is monetization and economics.
- **Growth:** focus is repeatable acquisition and scale.

## Step 2 — What is the current constraint?

Pick **one**:

- clarity;
- scope;
- technical;
- quality;
- users;
- distribution;
- positioning;
- trust;
- compliance;
- pricing;
- monetization;
- retention;
- team;
- capital;
- decision paralysis;
- founder execution.

If solving it would not materially move the project toward the next milestone, it is probably not the primary constraint.

## Step 3 — What is the safest useful exposure today?

- problem interview;
- landing page;
- waitlist;
- clickable prototype;
- concierge MVP;
- internal alpha;
- invite-only alpha;
- closed beta;
- public beta;
- production.

Do not stay private simply because public production is not yet appropriate.

## Step 4 — What evidence do you have?

Weak to strong:

1. founder belief;
2. compliments;
3. survey intent;
4. waitlist/signup;
5. target user gives time;
6. target user completes core action;
7. user returns without being chased;
8. user refers someone;
9. user pays;
10. user keeps paying or renews.

## Step 5 — Choose your Thursday track

- **VALIDATE** — no product or weak evidence.
- **UNBLOCK** — technical or execution blocker.
- **TEST** — something usable exists.
- **LAUNCH** — product works but is not exposed.
- **GTM** — launched but needs users.
- **B2B SALES** — needs qualified customer conversations.
- **DATA** — has users but weak behavioral understanding.
- **RETENTION** — users try but do not return.
- **MONETIZE** — value exists but revenue model is unclear.

## Output

Write one sentence:

> Our next end state is **___**. The current constraint is **___**. Before next Thursday, we will **___**, and we will bring **___** as evidence.
