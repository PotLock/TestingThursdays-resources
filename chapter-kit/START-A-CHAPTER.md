# Start a Chapter

A chapter should be reproducible without depending on one charismatic organizer.

## Minimum

- recurring time/location or reliable remote format;
- lead facilitator;
- clear founder intake;
- tester rules;
- breakout format;
- feedback capture;
- commitment process;
- simple program metrics;
- code of conduct/community expectations;
- consent/recording practices where relevant.

## First-session objective

Do not maximize attendance. Prove that a small group can:

1. identify real constraints;
2. test useful artifacts;
3. make decisions;
4. ship or commit to concrete actions;
5. return with evidence.
