# Monthly Program Retrospective

Ask:

## Start

What would make founders move faster?

## Stop

What consumes time without producing useful evidence or outcomes?

## Continue

What consistently creates value?

Also ask:

- Did the program help you reach a milestone sooner?
- What blocker repeatedly went unsupported?
- Which breakout was most useful?
- Which resources were missing?
- Did the facilitator help identify the true constraint?

Choose one program experiment for the next month.
