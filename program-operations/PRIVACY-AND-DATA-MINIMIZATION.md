# Privacy and Data Minimization for Sessions

The program should collect only what it needs.

## Avoid collecting by default

- government identifiers;
- payment credentials;
- private account passwords;
- unnecessary home/work addresses;
- personal medical information;
- confidential customer datasets;
- API secrets/tokens;
- production database exports.

## For testing

Prefer:

- demo/test accounts;
- synthetic test data;
- sandbox payment flows;
- redacted screenshots/logs;
- aggregate metrics;
- consent-aware recordings.

Founders remain responsible for appropriate privacy, security, and compliance practices for their own products.
