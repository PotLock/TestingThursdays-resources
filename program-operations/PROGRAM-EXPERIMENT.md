# Program Experiment Template

Testing Thursdays should test itself.

```text
PROGRAM PROBLEM
HYPOTHESIS
CHANGE
DURATION
METRIC
BASELINE
RESULT
DECISION: KEEP / CHANGE / STOP
```

Examples:

- Does a Tuesday checkpoint improve commitment completion?
- Does a 45-minute ship sprint increase same-night shipping?
- Do stage-based breakouts improve founder satisfaction and milestone movement?
