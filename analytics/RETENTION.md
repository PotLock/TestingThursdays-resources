# Retention

Retention should match the product's natural usage frequency.

A daily language-learning product and an annual filing product should not use the same retention expectation.

Segment churn:

- never activated;
- activated then left;
- price churn;
- technical churn;
- trust churn;
- need ended;
- competitor switch;
- involuntary billing churn.

Study both successful retained users and failed cohorts.
