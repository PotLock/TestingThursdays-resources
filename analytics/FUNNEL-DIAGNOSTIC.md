# Funnel Diagnostic

A common sequence:

```text
acquisition → signup → activation → retention → revenue → referral
```

## Interpret bottlenecks

- impressions but no click → audience/message;
- click but no signup → proposition/trust/landing friction;
- signup but no activation → onboarding/product friction;
- activation but no return → weak repeat value or wrong cadence;
- retention but no payment → monetization/value/pricing/buyer mismatch;
- payment but high churn → value, expectation, service, or fit issue.

Work on the narrowest consequential bottleneck, not every stage at once.
