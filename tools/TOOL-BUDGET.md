# Tool Budget Discipline

## Validation

Aim for close to zero software spend where possible.

## Prototype

Pay only when a tool meaningfully accelerates validation.

## MVP

Spend on essential infrastructure, monitoring, and bottlenecks.

## Growing

Add tools when they remove demonstrated operational constraints.

Quarterly ask:

> Which tool would we remove if we had to cut the stack by 30%?

Installing software can become a form of founder procrastination.
