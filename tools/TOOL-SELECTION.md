# Tool Selection

Choose a tool because a real problem requires it.

## Categories

- **Forms / intake:** lightweight form tools.
- **Feature-request management:** persistent request boards.
- **Analytics / replay:** product analytics tools.
- **Error monitoring:** error/crash monitoring.
- **Issue execution:** engineering/project issue trackers.
- **Human research:** prototype/usability testing platforms.
- **Web automation:** browser E2E tools such as Playwright.
- **Mobile automation:** mobile workflow tools such as Maestro.
- **AI-assisted QA:** specialized QA agents where they reduce real effort.

## Every tool entry should answer

- What problem does this solve?
- At what stage is it useful?
- What is the free/open-source alternative?
- What is the advanced alternative?
- When should a founder **not** install it yet?

A founder with zero users does not automatically need an enterprise research stack.
