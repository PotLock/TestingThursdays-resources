# Test Mission

**Target user context:**

**Situation:**

**Goal:**

Write a goal, not click instructions.

Example pattern:

> You need to accomplish [real outcome]. Use the product as you naturally would.

## Founder observes

- first action;
- hesitation;
- wrong turns;
- help request;
- error;
- recovery;
- completion;
- trust/distrust;
- unexpected delight.

## End questions

- What did you expect to happen?
- What was unclear?
- What would you normally use instead?
- What would stop you continuing?
