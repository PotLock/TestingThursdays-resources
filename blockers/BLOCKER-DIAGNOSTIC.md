# Blocker Diagnostic

Ask:

> What is the single biggest constraint preventing the next meaningful end state?

## Categories

- CLARITY
- SCOPE
- TECHNICAL
- QUALITY
- USERS
- DISTRIBUTION
- POSITIONING
- TRUST
- COMPLIANCE
- PRICING
- RETENTION
- TEAM
- CAPITAL
- DECISION
- FOUNDER EXECUTION

For every stated blocker ask:

1. If solved, what milestone becomes possible?
2. Does core value depend on this?
3. Is it required for safety/compliance?
4. Could it temporarily be manual?
5. Could exposure be limited to a small beta?
6. Could an existing tool solve it?
7. What evidence says this is the highest-value constraint?

If the same blocker survives multiple weeks, trigger a deeper blocker clinic rather than repeating the status update.
