# Messaging Lab

Test the message independently from the product.

## Five-second test

Show a landing page or store listing briefly, then ask:

1. What do you think this does?
2. Who is it for?
3. What problem does it solve?
4. What would you do next?
5. What was unclear?

## Positioning battle

Create 2–3 messages with materially different value framing. Show each to separate testers where possible. Record comprehension and qualified intent.

## Avoid

- founder vocabulary;
- long feature lists;
- claiming differentiation users do not care about;
- testing only aesthetic preference.
