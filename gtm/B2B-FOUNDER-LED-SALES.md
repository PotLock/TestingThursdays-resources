# B2B Founder-Led Sales

Early founders should usually understand the sale themselves before outsourcing it.

## Roles

- **User:** uses the product.
- **Champion:** wants it internally.
- **Buyer:** controls budget.
- **Decision maker:** can approve.
- **Blocker:** procurement, security, legal, integration, or another gate.

## Early sequence

```text
ICP → account list → research → outreach → discovery → demo → pilot → objections → procurement → close → implementation → renewal
```

## Do not demo too early

Discovery questions:

- Walk me through how you handle this today.
- When did this last happen?
- Who is involved?
- What goes wrong?
- How often?
- What does the problem cost in time, money, risk, or missed opportunity?
- Who would approve a change?
- When does this become urgent?

## Evidence ladder

Friendly interest < demo request < real workflow access < pilot commitment < paid pilot < contract < renewal/expansion.
