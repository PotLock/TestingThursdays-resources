# Test Method Selector

Choose the method based on the question.

- **Can people understand the proposition?** → five-second test.
- **Where do they click?** → first-click test.
- **Can they complete a task?** → task-based usability test.
- **Why are they struggling?** → moderated session.
- **How do they organize/find information?** → card sort/tree test.
- **What do production users do?** → analytics/session replay.
- **Does functionality break?** → automated/manual QA.
- **Did UI unintentionally change?** → visual regression.
- **Will a buyer pay?** → pricing/sales experiment, not a preference survey alone.

Use the cheapest method that can credibly answer the current question.
