# Common Testing Mistakes

- “It works on my phone.”
- Only testing the happy path.
- Founder explains the interface.
- Testing individual controls instead of real journeys.
- Asking leading questions.
- Recruiting only friends or developers.
- Confusing opinion with behavior.
- Turning every complaint into a feature request.
- Fixing low-impact polish before core failures.
- Testing only fresh accounts.
- Ignoring slow networks or permission denial.
- Failing to record environment and reproduction steps.
- Treating AI-generated feedback as real user evidence.
- Collecting more feedback after the problem is already understood instead of fixing it.
