# Consumer Mobile App Test Pack

## Core funnel

```text
install → first open → permissions → onboarding → first value → repeat action → re-entry → paywall → retention
```

## Test

- fresh install;
- returning user;
- denied permissions;
- notification behavior;
- deep links;
- offline/degraded network;
- app restart/backgrounding;
- keyboard overlap;
- small screen/text scaling;
- account recovery/deletion;
- upgrade/migration;
- subscription state where relevant;
- crash/error monitoring;
- store metadata/screenshots.

Do not optimize referral systems or sophisticated monetization before users consistently reach core value.
