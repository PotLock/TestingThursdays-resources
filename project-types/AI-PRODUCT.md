# AI Product Test Pack

## Build an eval set

Include representative, ambiguous, adversarial, long, multilingual, and failure-prone inputs appropriate to the product.

## Test

- output quality;
- hallucination/fabrication risk;
- model outage/fallback;
- latency;
- rate limits;
- cost per useful outcome;
- prompt injection or untrusted-input risks where relevant;
- privacy/data boundaries;
- model/version regression;
- human review/escalation for consequential outputs.

Do not evaluate an AI product solely by trying a handful of prompts and deciding it “looks good.”
