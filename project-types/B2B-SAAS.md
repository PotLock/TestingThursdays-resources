# B2B SaaS Test Pack

## Success path

```text
qualified account → discovery → champion → evaluation/pilot → implementation → repeat workflow → renewal/expansion
```

## Product testing

- user workflow completion;
- role/permission differences;
- onboarding/implementation effort;
- data import/export/integration;
- admin and reporting only where required;
- failure/recovery;
- support.

## Market testing

- ICP specificity;
- urgency;
- buyer vs user distinction;
- security/procurement blockers;
- pilot success criteria;
- willingness to commit to a next step.

Avoid interpreting employee enthusiasm as purchasing intent.
