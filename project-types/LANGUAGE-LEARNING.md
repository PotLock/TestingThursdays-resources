# Language-Learning Product Test Pack

Separate product engagement from learning outcomes.

## Product metrics

- first lesson started;
- first lesson completed;
- second lesson started;
- speaking/listening activity attempted;
- review activity completed;
- D1/D7 return at an appropriate cadence.

## Learning evidence

- recall after delay;
- comprehension;
- pronunciation/speaking attempts where relevant;
- transfer into real-world use where appropriate.

## QA

- audio playback;
- microphone permission denied/retry;
- correct/incorrect answer handling;
- unicode/language-specific input;
- progress persistence;
- restart/resume;
- offline behavior;
- content loading;
- streak/progress calculations;
- subscription states.

A highly engaging product that does not help users achieve the learning outcome may still be failing its purpose.
