# Recruiting Quality

The most useful tester is not always the most available person.

Evaluate:

- target segment match;
- currently experiences the problem;
- uses an existing workaround/alternative;
- has realistic context/device/environment;
- has intent or reason to change.

Tag every test:

- TARGET USER
- PLAUSIBLE USER
- NON-TARGET PEER
- DOMAIN EXPERT

Analyze them separately. Peer-founder feedback is useful, but it should not be confused with target-user validation.
