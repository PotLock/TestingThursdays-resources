# App Store Readiness

## Metadata

- app name;
- subtitle/short description where applicable;
- long description;
- category;
- support URL;
- privacy URL;
- age/content declarations;
- data/privacy declarations;
- in-app purchase/subscription metadata;
- review notes and reviewer credentials when needed;
- release notes.

## Assets

- correct app icon;
- current screenshots;
- no debug/staging UI;
- no placeholder data that misrepresents the product;
- screenshots fit required device classes where applicable.

## Build

- production API/auth;
- analytics/error monitoring;
- correct package/bundle identity;
- version/build number;
- production push/deep-link setup where applicable;
- account deletion and subscription handling where required.

Platform requirements change; verify current official guidance before submission.
