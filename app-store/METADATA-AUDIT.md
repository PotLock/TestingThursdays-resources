# Metadata Audit

For mobile/web releases, verify required metadata exists and is current.

## Mobile

- name/title;
- descriptions;
- privacy/support URLs;
- version/build;
- store screenshots;
- categories/ratings/declarations;
- subscription metadata where applicable.

## Web

- `<title>`;
- meta description;
- canonical URL;
- Open Graph metadata;
- social preview image;
- favicon;
- robots/sitemap where relevant;
- 404 page;
- privacy/terms/support links where relevant.

Automate presence checks where possible; use human/AI review for clarity and quality.
