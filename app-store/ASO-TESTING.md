# App Store Optimization Testing

Treat the store page as a funnel:

```text
impression → product-page view → install → first open → activation
```

## Blind test the listing

Ask someone who has not seen the product:

1. What does the app do?
2. Who is it for?
3. Why would you install it?
4. Which screenshot carries the value proposition?
5. Which screenshot adds little?
6. What would you search for before knowing the brand name?

Optimize for qualified installs and activation, not impressions alone.
